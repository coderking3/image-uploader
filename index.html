guest@king3/image:~$ curl -s /api/myinfo

Name

king3 image借助第三方 API 的图片上传服务，基于 Nitro 构建。

Synopsis

扫码登录或手动提交凭证，登录后上传图片，获取可以直接访问的图片 URL。服务端不落库、不做二次处理，登录凭证通过 HttpOnly Cookie 保存。

Endpoints

  • POST /api/auth/certificate 验证 SESSDATA 与 bili_jct 并登录
  • GET /api/qrcode/generate 生成登录二维码
  • GET /api/qrcode/poll?qrcode_key= 轮询扫码状态，登录成功后写入凭证 Cookie
  • GET /api/myinfo 获取当前登录账号信息
  • POST /api/upload 上传图片，multipart/form-data，字段名 file
  • POST /api/auth/logout 退出登录并清除凭证 Cookie

Authentication

扫码登录或手动登录成功后，SESSDATA 与 bili_jct 会自动写入 HttpOnly Cookie。 浏览器同源请求无需额外处理；跨域请求需要启用 credentials，curl 等非浏览器客户端可以手动携带 Cookie。

Example

curl -X POST /api/upload \
  -H "Cookie: SESSDATA=...; bili_jct=..." \
  -F "file=@avatar.png"
