Name

k3img借助 bilibili API 的图片上传服务，基于 Nitro 构建。

Synopsis

扫码登录，拿到凭证；上传图片，拿到可以直接访问的图片 URL。 服务端不落库、不做二次处理，凭证以 httpOnly Cookie 形式下发，前端和 CLI 脚本均可复用同一套接口。

Endpoints

  • GET /api/qrcode/generate 生成登录二维码
  • GET /api/qrcode/poll?qrcode_key= 轮询扫码状态，登录成功后写入凭证 Cookie
  • GET /api/myinfo 获取当前登录账号信息
  • POST /api/upload 上传图片，multipart/form-data，字段名 file

Authentication

调用 /api/qrcode/poll 扫码成功后， SESSDATA 与 bili_jct 会自动写入 httpOnly Cookie，同源请求下无需手动携带；跨域调用请 自行在请求头中附带 Cookie。

Example

curl -X POST /api/upload \
  -H "Cookie: SESSDATA=...; bili_jct=..." \
  -F "file=@avatar.png"
